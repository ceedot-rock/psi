# Session thrift rites — run at open and close, every session

Companion to `PRINCIPLES.md`. Checklists only; the laws carry the reasons.

## OPEN (first turn, before any tool call)

- [ ] Single goal stated; multi-goal work split first (T02).
- [ ] Prompt-prefix order set: system, skills, memory (T01).
- [ ] Stop condition written down (T12).
- [ ] Narration off for mechanical legs (T13).

## CLOSE (last turn, before handoff)

- [ ] New repeated context promoted to memory, atomically (T40, T42).
- [ ] Decisions + reasons snapshot; settled questions to do-not-re-derive (T43, T45).
- [ ] Stale notes demoted (T41); expired time-bound notes removed (T44).
- [ ] Report is deltas only: files changed, tests observed (T30).
- [ ] Scratch cleaned so listings stay tight (T10).
