# Layered memory (tweak 21) — working, episodic, semantic.
- working: this session's live context. Dies with the session.
- episodic: observatory.jsonl. Append-only, dated, sourced. Promotion: anything
  surprising or twice-useful graduates here within the session that learned it.
- semantic: distilled principles (this file's siblings, identity.md, env-model).
  Promotion: an episodic pattern confirmed 3+ times becomes a principle; the
  principle links back to its episode lines.
- Demotion: a principle contradicted by new evidence returns to episodic as a
  surprise, never silently edited.
